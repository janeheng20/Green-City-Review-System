# Green City Review System

## Project Overview
Welcome to **Green City Review System**, a simple C++ console application that allows users to explore and evaluate the environmental impact of various smart and green technologies. The system provides information on how much carbon footprint or energy can be reduced by using eco-friendly transportation and appliances.

## Features
- **Transportation**:
  - Electric Vehicle (EV) vs Petrol Car carbon comparison
  - Electric Bike vs Petrol Motorcycle carbon comparison

- **Home Appliances**:
  - Inverter Air Conditioner vs Old Model: Electricity savings
  - Energy-Efficient Fridge vs Old Model: Electricity savings

- **Interactive Menu**:
  - Choose product by product code
  - Input weekly usage or distance
  - Get immediate environmental impact feedback

## How to Use

- **Start the Program**: Launch the program to begin the interactive session.  
- **View the Menu**: A list of smart technologies (vehicles and appliances) will be displayed along with their product codes.  
- **Choose to Proceed**: When prompted, enter `Y` if you want to check your product’s carbon or energy savings.  
- **Enter Product Code**: Type in the product code (e.g., `001`, `002`, `003`, or `004`) to proceed with the analysis.  
- **Input Usage Details**:  
  - For electric vehicles or bikes: Enter the average distance you travel per week.  
  - For air conditioners: Enter how many hours you use them weekly.  
  - For fridges: The system uses default full-time usage (24/7).  
- **View the Results**: The system will calculate and display:  
  - Carbon footprint comparison for transportation.  
  - Energy savings for appliances.  
- **Repeat or Exit**: Choose to analyze another product or exit the program.
